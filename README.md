1. Drive chứa trọng số và cấu trúc của model phân loại và phân đoạn: https://drive.google.com/drive/folders/1xoCVzptdheHFVrIwvFzrG-0uPU1EPwbj?usp=sharing
2. Data để train mô hình phân loại và phân đoạn: https://www.kaggle.com/datasets/mateuszbuda/lgg-mri-segmentation/data
3. File Colab để train model được nằm ở thư mục "Training_model"
4. Tải về drive chứa trọng số và cấu trúc model nếu muốn chạy luôn và đặt từng loại vào thư mục model
5. Nên chạy trên Ubuntu hoặc WSL (với Windows), cài đặt Tensorflow 2.19 và dùng CUDA với thư viện cuDNN 
6. Sau khi setup xong hết mọi thứ, chạy file app.py và tìm đến http://127.0.0.1:5000/ để sử dụng
